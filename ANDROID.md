# My App — Android app

Generated by Lewa Coder from the web project in this repo.

## Getting the files without a computer

1. Push this repo to GitHub (Lewa Coder does it: Workspace -> Push to GitHub).
2. Open the repo's **Actions** tab. **Build Android app** starts by itself.
3. When it finishes (3-5 minutes the first time), open the run and download:
   - **myapp-apk** — install this on a phone.
   - **myapp-aab** — upload this to the Play Store.
4. Unzip the APK artifact on your phone and tap the file to install. Android
   asks once for permission to install from unknown sources.

## Getting them on your own machine

    cd android
    gradle assembleRelease   # -> app/build/outputs/apk/release/
    gradle bundleRelease     # -> app/build/outputs/bundle/release/

## What is inside

- android/app/src/main/assets/www/ — your web project, exactly as written.
- MainActivity.java — a WebView that opens www/index.html and handles Back.
- The build is signed with Android's standard debug key, so it installs
  straight away. Replace signingConfig in android/app/build.gradle with your
  own keystore before you publish.

Package name: com.lewa.app.myapp — change applicationId and namespace in
android/app/build.gradle if you want a different one.
